# YOLO-Vision-Bot: 基于 Rust和视觉模型yolov8n.onnx开发的适用于反恐精英2：CS2，AI视觉瞄准助手

## 简介 (Overview)
YOLO-Vision-Bot 是一款基于 Rust 构建的高性能应用层（Ring 3）自动瞄准助手。本项目集成了 YOLOv8 目标检测模型与 ONNX Runtime 引擎（支持 CUDA 硬件加速），可实现超低延迟的实时屏幕捕获、敌人识别与自动化的鼠标操作指令分发。

由于采用标准的用户输入模拟，本项目能够在搭载用户态（Ring 3）反作弊系统（例如 CS2 的 VAC 系统）的环境中正常运行。

**⚠️ 免责声明 (Disclaimer)：** 本软件底层依赖操作系统标准的 API 调用（通过 `enigo` 库调用 `SendInput`）来模拟鼠标移动。这种纯应用层的操作对于内核级（Ring 0）反作弊引擎（例如穿越火线的 ACE、无畏契约的 Vanguard）完全透明，且必定会在底层驱动中被直接拦截。本项目代码仅供 Rust 并发编程学习、计算机视觉（CV）模型部署研究以及离线环境测试使用，请勿用于破坏任何网络游戏公平性的违规用途。

## 核心特性 (Features)
* **硬件异构加速：** 原生接入 NVIDIA CUDA 算力（基于 `ort` v2.0.0-rc 引擎），打通显卡通道，实现毫秒级的神经网络推理。
* **动态 ROI (物理级高倍镜)：** 极限截取准星周围 320x320 的物理区域并使用插值算法拉伸至模型要求的 640x640 尺寸。相当于开启无损 2 倍镜，在不占用额外显存的前提下完美放大目标特征。
* **零延迟极速打击：** 精准映射目标相对像素坐标，采用离散步长（Steps）移动算法彻底修复指针停顿，实现瞬间平滑锁敌与毫秒级开火。
* **全局硬件级中断监听：** 独立线程通过 `device_query` 异步轮询底层硬件键盘状态，提供不受游戏窗口阻塞的随时启动/暂停与紧急熔断机制。

## 技术栈 (Tech Stack)
* **开发语言:** Rust (Edition 2024)
* **AI 推理引擎:** ONNX Runtime (`ort` v2.0.0-rc.13)
* **视觉识别模型:** YOLOv8 (`yolov8n.onnx`)
* **核心依赖库:** `screenshots` (截屏), `image` (图像张量处理), `enigo` (键鼠模拟), `device_query` (硬件状态监听), `crossbeam` (线程间通信)

## 环境依赖 (Prerequisites)
* Windows 10/11 x86_64 操作系统
* NVIDIA 独立显卡
* 已正确安装的 CUDA Toolkit (v12.x 或 v13.x)
* 与 CUDA 版本匹配的 **cuDNN v9.x** (必须将 zip 压缩包内的 `bin`、`include`、`lib` 文件正确覆盖至 CUDA 安装目录)
* Rust 原生编译工具链 (`cargo`)

## ⚙️ 游戏内设置与灵敏度调优 (In-Game Settings & Tuning)

由于本程序通过物理像素计算相对偏移量，因此游戏内的画面与鼠标设置会直接影响 AI 的锁敌精度。在正式运行前，请务必进行以下调整：

### 1. 画面显示模式
请将 CS2 的游戏显示模式设置为 **全屏窗口化 (Windowed Fullscreen)** 或 **窗口化 (Windowed)**。
* **原因：** 独占全屏 (Exclusive Fullscreen) 模式下，操作系统的截屏 API 可能无法获取游戏画面（只能截到黑屏），并且应用层的鼠标模拟指令极易失效。

### 2. 鼠标灵敏度校准 (Sensitivity)
程序源码中采用了固定的像素缩放比例计算鼠标移动步长。如果你的游戏灵敏度不匹配，会导致以下现象：
* **准星总是“滑过了头” (过冲)：** 说明你的游戏内鼠标灵敏度**过高**，请在游戏设置中适当降低灵敏度。
* **准星总是“挪不到位置” (未达到目标)：** 说明你的游戏内鼠标灵敏度**过低**，请在游戏设置中适当提高灵敏度。
